# 自动待命排查

适用于 A、B 飞行板。此更新只增加 USB 串口诊断；待命条件、安装方向设置和遥测格式不变。
需要把更新后的对应飞行板程序烧录到板子，旧固件不会输出下面的新字段。

在开伞点火负载断开的地面测试中，固定好要检查的安装方向。
停在 PAD 时，正常状态输出和串口命令 `S` 都会打印一行 `[ARM]`。

示例（虚构数值，并非已经测到的故障）：

```text
[ARM] auto=ON | blocked_by_X=NO | fired=NO | gyro_cal=DONE | still_timer=0.30/10.00s | last_reset=GYRO age=0.30s a=9.610m/s2 g=5.420deg/s
```

这表示：静止计时现在只有 0.30 秒；0.30 秒前，转动读数 5.420°/秒超过了 5°/秒的限制，打断了计时。即使当前状态行已经显示正常，失败那一刻的读数仍然保留。

| 字段 | 意思 |
|---|---|
| `last_reset=ACCEL` | 加速度总读数没有通过约 9.31～10.31 m/s² 的检查 |
| `last_reset=GYRO` | 转动速度没有通过小于 5°/秒的检查 |
| `last_reset=ACCEL+GYRO` | 两项都没有通过 |
| `last_reset=IMU_DOWN` | 当时 IMU 被标记为不可用；此时保存的 a、g 不能当成有效测量 |
| `last_reset=NONE` | 尚未记录到静止检查失败 |
| `age` | 距离最后一次失败的秒数；很久以前的失败不一定还在阻止待命 |
| `blocked_by_X=YES` | 本次运行收到过解除待命命令，自动待命被停用 |
| `fired=YES` | 程序认为本次飞行已经触发过，阻止再次待命 |
| `gyro_cal=PENDING` | 校准尚未成功；原有 `[FILT]` 行会进一步显示 RUNNING 或 SKIPPED |

`still_timer` 原样显示当前控制逻辑使用的计时，并不另行证明传感器持续更新。
IMU 不可用时会改为显示 `baro_boot_timer`，这是现有的仅气压计备用等待计时，不是测量到的静止时间。

比较平放和发射方向的 `[ARM]`、`[FLT]`、`[FILT]` 行，可以检查导致失败的读数是否随安装方向改变。
这份诊断不能单凭一次超限区分真实晃动、振动、传感器偏差或读数故障；应先保留证据，再决定修正方式。
